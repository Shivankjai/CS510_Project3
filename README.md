# In this project a simple web app has been build that draws an Abstract Syntax Trees (AST).
-This is a simple web application built using .NET that visualizes Abstract Syntax Trees (ASTs) for MicroML. 
-The project was originally created by my professor, and I have currently clone it from his GitHub repository to continue development.

# How it Works
-Parses MicroML code and converts it to bracket notation
-Displays AST using jsSyntaxTree from JavaScript
- For now, the app accepts bracket notation directly as input for testing.
